# 使用指南

本文面向用户，补充 [README](../README.md) 的基本使用。阶段性发布与验收结果另见 [发布与验证记录](./RELEASE-VALIDATION.md)，不把模拟测试视为全部设备兼容保证。

## 链接粘贴

- 粘贴单个 HTTP / HTTPS URL，可选择作为 Markdown 链接、原文或图片插入；无效 URL 保留编辑器原生粘贴行为。
- 选择链接或图片后先插入默认标题（路径末段或域名），再按设置获取网页标题。失败或超时保留默认标题；选择原文不会请求网页。
- 标题获取默认超时为 1000 毫秒，可设为 0–10000；**0 表示不请求**，不是无限等待。超时只停止等待，已发出的请求不能通过当前 API 取消。
- 标题请求会访问目标网站；不希望发生该访问时关闭标题获取。不要用含真实凭证的 URL 测试或反馈问题。
- 请求完成时笔记、文件、选区或功能状态发生变化，会放弃替换标题；选择弹窗期间内容变化时会拒绝插入，请重新粘贴。

## 括号配对

开启括号匹配后，将光标放在可识别的配对符号旁，通过命令面板使用「跳转到匹配符号」或「选择到匹配符号」。设置中可调整高亮样式、颜色及是否高亮未匹配符号。

## 加密代码块

默认围栏标识符为 `nya`。创建该代码块并填写正文，点击「加密」设置密码；也可以把光标放在块内运行「加密代码块」命令。

- **解锁查看**：仅在当前视图显示明文，笔记仍保持加密；解锁后可以复制与编辑。
- **预览**：按保存的语言标识交给 Obsidian 渲染，允许第三方代码块插件参与；明文块也可打开预览。
- **加密保存**：点击编辑按钮，在独立弹窗中修改正文、公开备注或渲染语言，使用当前密码重新加密并锁定。支持 `Ctrl/Cmd + Enter`。失败保留草稿；有修改时取消、Esc 或点击外部需选择保存、放弃或继续编辑。
- **修改密码**：解锁后从「更多操作」进入，验证当前密码后设置新密码。旧备份仍能使用旧密码解密。
- **永久解密到笔记**：使用底部开锁按钮或命令面板，确认后将代码块替换为明文，无需先预览。已解锁时只需确认；编辑操作期间禁用该操作。明文可能进入同步、备份与版本历史。
- **自动锁定**：默认当前块闲置 5 分钟后锁定，可设为 0–120 分钟，0 表示关闭。编辑、修改密码及永久解密确认等操作等待期间均暂停锁定，结束后重新计时；不是切后台立即锁定。

### 数据与安全限制

- 密码无法找回；备注是公开信息，不受加密保护。插件不持久化密码或明文草稿。
- 草稿仅存在当前视图内存中。关闭笔记、切换模式、关闭功能、改变围栏标识符或退出应用可能丢失未保存修改，请先加密保存。
- 渲染语言是未认证的公开元数据。修改它可能改变解锁后的处理器，而不使正文解密失败；能解密不代表元数据可信。
- 第三方渲染插件可能执行查询、请求或其他副作用；仅预览可信来源内容，并使用可信插件。关闭预览会清理已注册的渲染资源，但不能撤回已发生的外部操作。
- 保存会校验原始块，冲突时拒绝覆盖；不能安全定位的嵌套 / 缩进块会拒绝操作。LF / CRLF 结构换行会分离处理，旧密文已保存的字面回车不会自动删除。
- 命令等待期间每文件只允许一个加解密命令。关闭功能、改变围栏标识符或卸载会取消待处理操作；切换笔记不会把目标改到新笔记，提交仍针对原文件并检查冲突。已发出的宿主写入不能保证撤销。

## 设置生效与保存

- 功能开关及标题获取设置无需重载。输入类设置在防抖提交或失焦后生效。
- 改变加密围栏标识符会切换处理器，**不会迁移已有笔记中的标识符**；关闭加密或改变标识符前先保存草稿。
- 界面语言即时切换；已经注册的命令名称需重新加载插件或 Obsidian 后更新。
- 恢复默认需确认，并废弃当前页尚未提交的输入 / 颜色草稿，即使默认值与旧值相同。
- 保存失败时新设置仍在当前会话生效，但不会提示恢复成功；可点击「重试保存」。成功前不要依赖重启后的持久化结果。

## 安装与加载排查

安装更新步骤见 [README](../README.md#安装与更新)。移动端可用文件管理工具或能同步隐藏配置目录的工具复制三个产物，不需要在手机安装 Node.js。

- 列表找不到插件：检查配置目录、目录层级及 manifest 是否完整同步。
- 启用失败：确认三个文件来自同一构建，不要混用新 manifest 和旧入口文件。
- 更新后仍使用旧文件：重新启用插件，必要时完全退出并重开 Obsidian。
- 需要反馈时，提供平台 / 系统版本、Obsidian 版本、插件版本、安装方式、最小复现和脱敏错误信息。不要提供密码、真实明文、完整 `data.json`、私人笔记库或带凭证的 URL；截图与日志先去除个人信息。

自动化加载使用宿主 API 替身，不能代替实际设备与第三方插件验收。具体边界见 [测试与验收](./TESTING.md)。
