# 测试与验收

面向开发者与 Agent；本文定义验证方法及边界，不记录某轮“已经通过”的状态。实际结果记录在 [发布与验证记录](./RELEASE-VALIDATION.md)。环境命令见 [开发环境](./DEVELOPMENT.md)。

## 自动化门槛

提交前执行 `pnpm check`，依次运行 Lint、回归测试和含 `tsc --noEmit` 的生产构建；另执行 `git diff --check`。不能跳过任一环节或放宽规则掩盖失败。依赖变更后使用 `pnpm install --frozen-lockfile` 验证安装可复现性，发布前再执行 [发布检查](./RELEASE.md#发布前检查)。

测试使用 Node 内置测试器，`pnpm test` 自动发现 `tests/*.test.mjs`，不需要新增测试框架。增加 / 修改行为时同步回归测试，优先断言实际模块、事件回调、构建与写回结果，而非只匹配源码字符串。

## 测试定位

- `project-constraints.test.mjs`：真实 ESLint 的运行时导入、Node 全局和脚本边界。
- `mobile-bundle.test.mjs`：真实 Vite 配置的开发 / 生产内存构建、单入口、必需产物、导入限制及无 Node 全局变量加载；不依赖旧 `dist/`。
- `runtime-regressions.test.mjs`：URL 校验、Markdown 转义、捕获位置、迟到标题保护、HTTP 超时及按编辑器隔离的括号命令。
- `settings-runtime.test.mjs`：按需注册 / 清理、设置校验、串行保存、输入防抖与零值、颜色草稿、同值重置、失败反馈和重试、开关语义。
- `crypto-block.test.mjs`：围栏与冲突、LF / CRLF 往返、密文互读、格式 / 认证 / 能力错误、存储校验、预览资源及中英文键集。
- `crypto-commands.test.mjs`：命令门禁、取消 / 卸载、密码弹窗及计算 / 排队写入失效。
- `crypto-edit-modal.test.mjs`：草稿、退出确认、保存失败重试、重复保存与销毁。
- `crypto-interactions.test.mjs`：工具栏路径、编辑保存、关闭功能后的保护、自动锁定及样式作用范围。
- `release.test.mjs`：tag、版本映射和构建 manifest 一致性，不证明入口文件来源。

## 自动化边界

当前不少测试替换 React hooks、Modal、编辑器、存储或宿主注册。它们能验证相应路径，但不是完整的 React DOM 调度或真实 Obsidian 集成，也不证明所有 WebView、软键盘、剪贴板和第三方插件可用。

模拟 bundle 加载不等于真实插件 `onload`、阅读模式 / Live Preview 都正常。密文互读不等于所有历史附件已验收；修改格式兼容层应使用人工构造或公开可复现的固定兼容样本，不能取真实私人密文。

尚缺的集成覆盖与待确认策略见 [验证记录](./RELEASE-VALIDATION.md#后续验证与待确认策略)，不要以增加替身断言冒充已完成宿主验收。

## 回归场景选择

- **设置**：快速输入 / 拖动、合法零值、非法类型、同值恢复默认、失焦 / 卸载、保存失败 / 重试；无关设置不破坏会话。
- **异步操作**：弹窗 / 计算 / 宿主排队期间输入、切文件、改选区、关闭功能、改标识符、卸载；重复执行不重入，原目标变化拒绝覆盖。
- **加密与文本**：LF / CRLF、空块、末尾空行、字面回车、历史字段、错误密码、坏格式、缺失 Web Crypto、重复 / 移动 / 删除的块及较大文档。
- **生命周期**：重复启停、关闭视图、迟到处理器、编辑草稿退出、自动锁定等待和计时恢复。
- **宿主能力**：最低支持版本的 API、旧渲染回退、阅读模式 / Live Preview、多编辑器和撤销。

## 移动端真机验收

涉及构建、依赖、编辑器或交互的发布，应在 Android / iOS 的独立测试笔记库执行，并同时回归桌面端。只用合成数据，更新前保存草稿并备份设置。

- [ ] 同一构建的三个文件正确安装；保留设置，全新启用与覆盖更新均能启动。
- [ ] 设置页切换 tab / 语言，键盘 / 触控可用；输入数字、拖动颜色后关闭或重启，合法值保存、非法值不写入、无明显卡顿。
- [ ] 功能开关即时影响实际行为，重复切换无重复弹窗 / 命令 / 高亮，关闭后无残留样式。
- [ ] 链接 / 原文 / 图片及无效 URL 正常；标题开关、零超时、失败回退正确；等待期间编辑、移动选区、切文件或禁用不覆盖新内容。
- [ ] 不同笔记及多编辑器中，括号高亮、双向跳转和选择不沿用其他编辑器的位置。
- [ ] 新建与历史兼容样本可加密、解锁、编辑保存、改密和永久解密；错误密码、冲突与取消不改文件，编辑器写回可撤销。
- [ ] 预览、自动锁定、编辑 / 阅读模式切换及前后台行为符合指南；关闭加密或改变标识符清理会话，无迟到写入。
- [ ] 在可获得的最低宿主版本验证加载与渲染回退；第三方处理器以可信测试插件单独验证资源清理。

只记录脱敏诊断，不记录私人路径、账号、设备序列号或真实笔记。无法确认验证对象的旧记录只能作为线索，不能升级为当前提交的通过证据。
