# Obsidian Mikansei

自用的 Obsidian 插件，包含功能：

- [x] 粘贴链接增强（自动识别网页标题，自动添加标签）
- [x] 括号配对（高亮配对、跳转、选择）
- [x] 自定义代码块加密解密存储和显示（加密存储、复制、预览、解密到源文件）

## 加密代码块

在 `nya` 代码块中填写正文，点击「加密」设置密码；也可以在代码块内运行「加密代码块」命令。

- **解锁查看**：仅在当前视图显示明文，笔记仍保持加密；解锁后可以复制和编辑。
- **代码块预览**：使用 Obsidian 的 Markdown 渲染器与保存的语言标识，允许已有代码块插件参与渲染；明文块也可通过「预览内容」打开预览。
- **加密保存**：点击底部编辑图标，在独立弹窗中编辑正文、公开备注或渲染语言，使用当前密码重新加密并锁定。支持 `Ctrl/Cmd + Enter`。保存失败保留草稿以便重试；有修改时取消、Esc 或点击弹窗外均需选择保存、放弃或继续编辑。
- **修改密码**：解锁后从「更多操作」进入，验证当前密码再设置新密码。旧备份中的密文仍可以用旧密码解密。
- **永久解密到笔记**：点击底部工具栏的开锁图标或使用命令面板，输入密码并确认后将代码块替换为明文，无需先打开预览。已解锁时只需确认；有未保存编辑时禁用此操作。明文可能进入同步、备份和版本历史。
- **自动锁定**：默认当前代码块闲置 5 分钟后锁定；设置中可调整为 0–120 分钟，0 表示关闭。编辑弹窗打开期间暂停自动锁定，退出编辑后重新计时。

备注是公开信息，不受加密保护。密码不能找回，插件不会持久化密码或明文草稿。编辑草稿只存在当前视图内存中，关闭笔记、切换模式或退出应用可能丢失未保存修改，请先加密保存。

预览中的第三方代码块插件可能执行查询、请求或其他副作用，请仅使用你信任的渲染插件。插件会在关闭预览时卸载已注册的渲染组件，但无法撤回第三方已执行的外部操作。

保存会校验原始代码块，笔记发生冲突时不会覆盖写入。不支持安全定位的嵌套/缩进代码块会拒绝操作。现有 AES-GCM / PBKDF2 密文格式保持兼容。

需要 Obsidian 1.1.0 或更新版本（使用 `Vault.process` 进行原子写回）。
