# Obsidian Mikansei

一个用于 Obsidian 的小工具插件，提供链接粘贴增强、括号配对，以及代码块加密与解锁查看。

## 安装与更新

需要 Obsidian 1.1.0 或更新版本，面向桌面端与移动端。

1. 下载对应 Release 的 `main.js`、`styles.css`、`manifest.json`。
2. 将三个文件放入笔记库的 `.obsidian/plugins/mikansei/`。使用自定义配置目录时，替换 `.obsidian`；不要多嵌套一层 `dist/`。
3. 在 Obsidian「设置 → 第三方插件」中允许并启用 Mikansei。

更新前保存编辑草稿并关闭插件，仅覆盖上述三个文件，**保留 `data.json`，不要删除整个插件目录**，随后重新启用插件。

- 将光标放在配对括号旁，通过命令面板跳转或选择到匹配符号。
