# Obsidian Mikansei

自用的 Obsidian 插件，包含功能：

- [x] 粘贴链接增强（转换为 Markdown 链接、原文或图片，可自动获取网页标题）
- [x] 括号配对（高亮配对、跳转、选择）
- [x] 自定义代码块加密解密存储和显示（加密存储、复制、预览、解密到源文件）

## 安装与更新

需要 Obsidian 1.1.0 或更新版本（使用 `Vault.process` 进行原子写回）。插件面向桌面端与移动端，不要求在手机上安装 Node.js。

1. 从对应版本的 Release 获取 `main.js`、`styles.css`、`manifest.json`；自行构建时使用 `pnpm build` 生成的 `dist/` 内同名文件，不要直接复制源码。
2. 在仓库的配置目录下创建 `plugins/mikansei/`，默认完整路径为 `.obsidian/plugins/mikansei/`，将三个文件放在该目录内，避免多嵌套一层 `dist/`。使用自定义配置目录时，以实际目录为准。
3. 在 Obsidian「设置 → 第三方插件」中允许并启用 Mikansei。移动端可通过文件管理工具或能同步隐藏配置目录的工具复制文件；确认三个文件属于同一版本且已完整同步。

更新前先保存编辑草稿并关闭插件，仅覆盖以上三个文件，**保留 `data.json`，不要删除整个插件目录**。同步完成后重新启用插件；移动端若仍使用旧文件，完全退出并重新打开 Obsidian。

### 移动端加载排查

- 插件列表中找不到：检查配置目录、目录层级和 `manifest.json` 是否已同步。
- 启用时报加载失败：确认三个文件版本一致，使用重新构建或发布的产物，不要只复制新 manifest 搭配旧 `main.js`。
- 仍然失败：反馈 Android / iOS 及系统版本、Obsidian 版本、插件版本、安装方式和报错原文或截图；有控制台日志时一并提供，不要上传密码或笔记明文。

自动化测试会在没有 Node 全局变量的环境中加载开发、生产构建，但使用了宿主 API 替身，不能证明所有手机环境和交互均正常。Android / iOS 仍需按[移动端验收清单](./docs/DEVELOPMENT.md#移动端真机验收)验证；当前修复尚未完成真机验证。

## 链接粘贴与设置生效

- 粘贴单个 HTTP / HTTPS URL 时，可选择作为 Markdown 链接、原文或图片插入；无效 URL 保留编辑器原生粘贴行为。
- 选择链接或图片后先插入默认标题（路径末段或域名），再按设置获取网页标题。请求失败或超时保留默认标题；选择原文不会请求网页。
- 默认超时为 1000 毫秒，可设为 0–10000；**0 表示不请求网页标题**，不是无限等待。超时后不再更新标题，但已发送的请求不能通过当前 API 取消。
- 网页标题返回后，若笔记内容、文件或选区发生变化，或功能已关闭、插件已卸载，则不再替换标题。选择弹窗期间笔记已变化时会拒绝插入，请重新粘贴。
- 链接增强、括号匹配、加密代码块开关，以及标题获取设置无需重载插件。输入类设置在防抖提交或失焦后生效。
- 修改加密代码块语言名称后会切换处理器，**不会自动替换已有笔记中的围栏标识符**。关闭加密功能或修改此名称会清理原渲染会话，操作前先加密保存编辑草稿。
- 界面语言即时切换；已注册的命令名称需要重新加载插件或 Obsidian 后更新。

## 加密代码块

在 `nya` 代码块中填写正文，点击「加密」设置密码；也可以在代码块内运行「加密代码块」命令。

- **解锁查看**：仅在当前视图显示明文，笔记仍保持加密；解锁后可以复制和编辑。
- **代码块预览**：使用 Obsidian 的 Markdown 渲染器与保存的语言标识，允许已有代码块插件参与渲染；明文块也可通过「预览内容」打开预览。
- **加密保存**：点击底部编辑图标，在独立弹窗中编辑正文、公开备注或渲染语言，使用当前密码重新加密并锁定。支持 `Ctrl/Cmd + Enter`。保存失败保留草稿以便重试；有修改时取消、Esc 或点击弹窗外均需选择保存、放弃或继续编辑。
- **修改密码**：解锁后从「更多操作」进入，验证当前密码再设置新密码。旧备份中的密文仍可以用旧密码解密。
- **永久解密到笔记**：点击底部工具栏的开锁图标或使用命令面板，输入密码并确认后将代码块替换为明文，无需先打开预览。已解锁时只需确认；有未保存编辑时禁用此操作。明文可能进入同步、备份和版本历史。
- **自动锁定**：默认当前代码块闲置 5 分钟后锁定；设置中可调整为 0–120 分钟，0 表示关闭。编辑弹窗打开期间暂停自动锁定，退出编辑后重新计时。

备注是公开信息，不受加密保护。密码不能找回，插件不会持久化密码或明文草稿。编辑草稿只存在当前视图内存中，关闭笔记、切换模式、关闭加密功能、修改代码块语言名称或退出应用可能丢失未保存修改，请先加密保存。

预览中的第三方代码块插件可能执行查询、请求或其他副作用，请仅使用你信任的渲染插件。插件会在关闭预览时卸载已注册的渲染组件，但无法撤回第三方已执行的外部操作。

保存会校验原始代码块，笔记发生冲突时不会覆盖写入。不支持安全定位的嵌套/缩进代码块会拒绝操作。现有 AES-GCM / PBKDF2 密文格式保持兼容。
